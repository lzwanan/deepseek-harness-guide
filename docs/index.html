模型只会吐字。
让它动手的，是 harness。

这是 DeepSeek Harness 的导读，不是一个模型的使用手册。七章，从「它到底是什么」一路讲到「为什么这段代码你不能随便改」。每章只加一个新概念，配一个能看清因果的动画。
